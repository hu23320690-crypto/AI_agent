# intent_v1 固定评分合同（P0）

本规则与全部标签在规则解析、LLM 推理及 P1 实现之前编制。P0 固定候选字节和 SHA256，项目作者审核金标准后才能正式准入。当前 `gold_review_status=pending_author_review`，不是已获作者认可。冻结后不根据评测输出修改题目、标签、规则或分母；发现标注错误须另发修订版并保留原版。

## 输入与授权目录

- `cases.jsonl` 共140条（dev40/test100）；`dev.jsonl`、`test.jsonl`与相应行逐字相同。P1/P2只允许读取 `dev.jsonl`，不得打开合并文件、test、test审核清单或Agent测试题面。P0编制/静态核对/作者审核是本次明确要求；封存后到P3不得再读test，不以编题记忆调参。
- `user_id` 是评测注入的受信会话身份，不是自然语言授予的权限。`lookups` 仅包含月份与 `phase=current|history`，按数组顺序代表已完成查询；不存在手写字段目录。
- 字段目录仅由冻结CSV中该用户、这些查询月的成功记录提取：依次读取“清洁效率”“耗材”，将字面 `\\n` 还原为换行，以首个中/英文冒号分割，取非空左侧字段名并按首次出现去重。找不到该用户/月的记录不生成字段；不得加入其他月份、用户或全库字段。
- history查询只提供已授权目录，不自动提供相对月锚。`fallback_month` 是最后一次current查询的合法月份（包括正确返回not_found的请求月）；无current则null。history最多3条、UTF8合计不超过1024字节，只含用户原话；`previous_intent`提供上一有效意图的绝对月份。
- 输入允许指向未获数据的月份。组件正确解析该选择不等于该月已查证，不授予新增查询/读取/输出数值的权限；最终渲染必须另验当轮查询。无记录不改变请求目标，也不能补零或改查邻月。
- `today`固定为每题明确日期，只用于身份记录及未来合法上下文。作者已于2026-10-13确认按计划V8处理：相对说法缺previous目标和current查询月时，`unresolved_month=true`，不得用today猜月。该澄清只认可此口径，不代表全体金标准已审核。

## 标签与唯一解释

`gold`九个槽位必须完整；null与空串不同，布尔值不得用整数代替：

| 槽位 | 固定解释 |
| --- | --- |
| fields | 用户肯定要求且属于本会话目录的标准字段名，按请求顺序有序去重；不丢部件、范围、模式或方位限定。 |
| unknown_fields | 肯定请求、但目录不提供的具体指标名；保留题面中的指标名，不把未知换成近似字段。被明确撤回/排除的字段不在此列。 |
| limited | 只交付明确选择的字段/未知项为true；即使没有“只”字，明确限定几个指标也为true。 |
| full_report | 当前明确要求完整/全部报告才为true；字段与未知列表为空且limited=false。没有限定的普通“看报告”属于unspecified（false/false），不得把隐含默认渲染当显式完整意图。 |
| target_month | 当前肯定请求所指合法YYYY-MM；无可确定目标则null。 |
| compare | 当前仍要求两期比较时为true；明确取消则false。不得仅因否定语句包含“比较”或数值描述包含“增加”就开启比较。 |
| comparison_month | 基准月份；不比较时必须null。基准可以晚于目标；顺序与工具调用顺序不决定语义角色。 |
| knowledge_requested | 当前另有实际需要知识资料的解释/条件/定义子问为true；只是报告字段名含“原因”等、或明确否定说明，不构成知识请求。不得从旧轮自动继承已取消的知识请求。 |
| unresolved_month | 请求存在无法确认的目标或基准月份时true；合法但无数据的月份不是“无法确定”。 |

`requested_field_order`是九槽之外的顺序标注，记录已知和未知指标混排的全序；它的内容必须等于两列表的并集、无重复。字段顺序指标及整体完全正确同时核验此全序，避免两个列表各自正确却将未知项移到末尾。完整或unspecified报告的该列表为空，目录自身默认顺序不另计意图准确率。P2适配时以最终ReportIntent中保留的混合字段序列比较，不能根据当前受测输出生成顺序标签。

规则解析器现有ReportIntent把未知名称放在同一个fields序列中；未来评测适配只按当题动态目录将它拆为已知/未知并保留原全序。`full_report`须有scope或明确原文的评测观测依据，不能仅用 `not limited` 代替。这里冻结的是语义合同，不要求P0实现适配器。

月份解释先用当前正向明确角色/更正；相对目标以previous有效目标为锚，否则以current查询月为锚。相对基准以本轮确定的目标月为锚；“环比”是目标前一月，“三个月前”减3个月，跨年由日历算术确定。裸月/同年沿用有效previous目标年份，其次current年份；无有效年份不得猜。未取得数值的明确月份可以保留为合法意图锚，但不是数据授权。当前明确字段/顺序/范围/否定优先于历史；真实指代才继承最后有效选择。

比较主指标时只允许去除字符串两端空白、统一换行，以及按题面已声明的去重处理；标准字段名必须精确相等，不接受“包含关系”映射、任意同义表扩张或擅改限定词。未知字段在去除空白后，与题面原词或该题 unknown_aliases 中列出的等价写法一致即可；字段别名→标准名的正确性由冻结gold定义，不能来自受测规则输出。

`unknown_aliases` 是题目级、事先列定的未知字段等价写法；本次仅 IT085 登记 `["每日耗水量"]`，对应 gold 中的“每天耗水量”。其余题不增加等价写法。接受等价写法时，未知字段集合及 `requested_field_order` 同一未知项位置按 gold 原词核对，不改变已知/未知分类或混排位置；不得用于已知字段、目录匹配或扩张全局同义表。已知标准字段名仍必须精确匹配。

## 分母、主指标与错误分级

- 主指标：test100条整体意图完全正确率，九槽和合并字段全序都一致、执行成功才通过。dev单列40条，不混入test成绩。
- 分槽位：已知字段集合、未知字段集合、合并字段顺序、目标月、基准月、compare、范围（limited+full_report）、knowledge_requested、unresolved_month。所有槽位保留计划分母；集合相同不代表顺序正确。null槽位不是免评分槽位。
- 一题可留多个错误标记；汇总严重程度按 `dangerous > wrong_scope > safe_fail > other_error` 互斥归类，同时保留全部原始槽位差异。不能把所有错误都算成“安全回退”。
- dangerous：最终选择了gold未要的目录字段（含已否定项、丢限定词的映射），或目标/基准给出与gold不同的合法月份（gold=null也算）。给出正确未查询月份只是选择，不表示危险数据交付；是否误输出数值由Agent层判。
- wrong_scope：限定/完整/unspecified任一范围槽错误，且没有更严重危险错误。
- safe_fail：遗漏可答字段，正确字段降未知，或在可确定月份上选择null/unresolved等可见拒答；未知原指标不丢弃且明确“未提供”才是正确安全行为。若同时包含危险字段或月份，按dangerous。
- other_error：没有上述标记但排序、knowledge_requested、compare等仍错；错误严重程度不代替整体通过。
- 未执行、超时、异常、截断、非法结构、未复核保持100原分母，整体不通过；不能默认安全或正确，不剔除难题。记录执行失败/未知与语义错误两个维度。

## 正式运行、成本与后续准入

P0不运行任何受测解析器或模型。P1/P2只用dev；最多3轮dev调参，每轮记录版本及全部结果。P3正式实验只有一个预先登记批次：rule确定性1次；llm_only与hybrid各3次，以完整重复为单位报告均值及最差一次，不另选更好的重跑。每次使用新的结果目录并依计划封存。提前确定重复种子/身份、模型digest、采样和模式，不能见test后改。

分别记录回退率、V1–V10冲突码次数、预算跳过（分母为计划报告轮）、p50/p95与额外模型调用次数。延迟使用单轮墙钟，p95采用nearest-rank（ceil(0.95*n)），所有状态的耗时与成功耗时分别报，缺测/失败数单列。rule时间是主基线，不能把未实际测到的增量估成零。最差准确率取3次中最低，最差危险错误取3次中最高；不得拼成一个虚拟最好版本。

默认切换仍受计划G1–G6约束：rule行为回归一致；hybrid最差test完全正确率比rule高至少10个百分点；最差危险错误不多于rule；Agent任务通过不低于rule且逐案进步多于退步；已见题知识/拒答变化各≤1题且Agent不退步；新增报告轮延迟p95≤10秒且预算跳过≤5%。P0不切换默认、不新增配置，不更改任何实现/提示/参数/工具。旧generalization/holdout仅为已见题回归。

本题集使用同一份演示CSV，不是新数据源或跨领域验证。Codex助手团队参与编题及静态复核，尚待项目作者审核，非独立外部盲评；“未见”仅指未用于实现、提示调参及先验结果选择，不能声称编题者从未接触标签。全部原始失败与修订版须保留。
