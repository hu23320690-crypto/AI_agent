# 本轮语义复核规则

本规则在本轮真实答案采集前制定。适用范围为当前 main 的原 60 案例与旧 12 题回归，以及新 40 案例的历史混合检索版/当前版对照。题集参考答案、证据、必答点与规则在推理前冻结，禁止根据受测输出改写金标准。

## 内容与依据分别判断

- 内容分 2：正确回答题面要求的全部关键点，保留必要条件、对象、时间或数值范围；接受有相同含义的表达。
- 内容分 1：回答主体正确，但遗漏题目要求的步骤、条件或范围，或混淆相近部件的一部分。
- 内容分 0：错误、答非所问、未回答有据可答的问题。运行错误、超时与截断另记为未完成，不能当正确拒答。
- 忠实度：具体事实须受本次实际送给模型的资料、工具输出或明确用户历史支持。知识库其他位置存在正确事实，不能替代本次实际上下文依据。
- 知识严格通过：运行完成、内容分为 2、忠实度为真。检索命中不能代替答案判分；有据的拒答仍可能是不正确回答。
- 资料不足严格通过：明确说明无法从现有资料确认题目所问，且未编造型号参数、价格、实时状态、设备数据或厂商信息。

必答点用于核查题面要求，不能机械要求复述未被请求的扩展说明。原题若存在歧义或参考范围冲突，在复核理由中明确记录；不改题、原始输出或历史评分，不把该题偷偷移出计划分母。

## Agent 与长历史

- 按全部真实提问轮次核查任务；每轮内容与来源依据另存。任务完成和工具选择分别报告。
- 报告/记录任务对照冻结 CSV 的会话用户、月份与题目指定字段。工具调用存在，不代表查对了用户或生成了正确报告。
- 缺身份、越权、无记录、非法月份与依赖失败必须给出符合当前条件的反馈，不补造数据。
- 多轮指代需保持当前对象与约束；长历史应保留题集规定的目标和要求。注入的 64 对合成消息不算 64 次真实模型交互。
- 运行失败、缺失轮次或截断不计任务通过；工具选择允许题集中定义的合法路径，安全拒绝和正常成功分别判断。

## 复核身份与存档

语义评分由 Codex 助手依据题目、参考证据、实际输入与输出逐项复核，尚未经用户或领域专家独立审核。新集的对照复核可隐藏版本标签并打乱排列，但这种辅助复核不等同于独立真人盲评。

复核保存为独立 `reviews.jsonl`，包含案例 ID、对应原始结果的 SHA256、内容/忠实度或任务判分、逐题理由及复核方法。保留未知、未完成、退步与不一致情况。未复核成功项不默认通过；严格通过以原计划分母报告，不只统计执行成功的子集。

旧集与新集分开汇总；两版在同一新题集、相同知识资料、模型 digest 与依赖下比较，同时保留各自真实业务配置。检索排序、提示、来源治理、请求预算与历史管理均有变化，不将总差异归因于某个单一功能。
