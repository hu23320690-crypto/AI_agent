# intent_agent_v1 固定评分合同（P0）

本集12个Agent任务、每例恰好2轮，共24次真实用户提问；没有合成历史充数。它是P3的端到端测试集，P1/P2不得打开题面或金标准。P0编制、静态核验和作者审核属于本次明确要求，固定候选SHA后停止读取。正式实验准入仍待项目作者审核，不把候选提交当成已审核。

内容分、忠实度和全轮任务通过沿用 [generalization_v1/SCORING.md](../generalization_v1/SCORING.md)，该规则SHA在manifest中记录。以下只明确这12个任务的分母及报告要求，不因受测输出更改判据。

## 逐轮与全轮交付

- 内容2：完成该轮明确请求的全部字段、月份、比较角色、差值、范围及知识条件，允许等价措辞、数值写法；内容1为遗漏/部分正确，0为核心错误、答非所问或未回答可答题。
- 忠实度另判：所有核心及新增具体事实须有本轮有效授权查询、有效同会话证据、用户明确提供的背景或经生产校验的来源引用支持。工具/检索成功不能证明最终交付正确。
- 单例任务通过要求全部2轮执行完整、内容2、忠实度真、该轮必答要求成立。计划分母固定12任务/24轮；超时、异常、未执行、截断和缺评分保留分母，不默认通过。
- `gold_intent`仅是评审辅助，最终任务判定是内容+证据+交付，不把解析槽位对了当端到端通过；可单列槽位结果。`record_checks`、`comparison_checks`及source行引用提供核对依据，不属于模型输入。答案没有这些JSON键不会因此扣分。
- 会话身份固定为case.user_id，不可由题面/模型修改。当前目标数字必须来自本轮真实授权fetch；比较基准可来自本轮或同一会话此前有效查询，不强制重复同一基准查询。目录仅由该用户成功查询生成；无记录不提供新目录。
- 报告只列所要字段；已知/未知混排按用户顺序，重复项首次出现去重，明确新顺序和范围覆盖历史。仅限报告字段不否定另一个肯定知识子问；明确取消知识说明时不得继续追加。
- 无记录必须明确正确用户与请求月份，不能挪邻月、补零或估值。合法的无记录月份仍可作为后续用户明确月份/年份锚；它不提供目录或数字授权。未知指标必须原名说明未提供，不能以近名或别的部件替代。
- 比较必须交付目标值、基准值及目标减基准的方向/差值；%相减用百分点，天/㎡等单位保留，missing不能当零。明确取消比较后不继续输出旧基准或差值。全量报告需覆盖该月效率/耗材实际项目，不以任意少数几个字段冒充完整；不额外强制题目未要的背景建议。
- 知识组合必须交付相应全部条件和对象边界。电池衰减不是当前续航/原续航；不借百分数或补数诊断设备是否达到更换门槛。边刷本体与卡扣的周期/条件不能互换。核心及新增知识事实均按实际证据评分，不能凭库中另处存在某句就给忠实通过。

## 工具与运行

每轮至少要求一次 `fetch_external_data`；引入新资料的知识子问另要求本轮 `rag_summarize`。已经有同会话有效资料时可以复用，不强迫重复知识查询：IA005第2轮设置 `knowledge_evidence_policy=prior_verified_evidence_allowed`，只必须本轮查新月记录，可依据第1轮仍有效的门槛条件判断数据不足。knowledge_requested描述子问题意图，不等同每轮必须新检索。required_tools/allowed_tools只评分工具选择，授权、用户/月参数、执行状态及最终内容另查。报告所需既有身份/月辅助工具在allowed_tools中列出，不能据辅助工具改变用户明确的历史月份。禁止把正确工具名当任务完成；无必需知识的报告轮不增加不相关工具。

P0没有推理结果。P3的rule与hybrid各完整串行运行1次（12例/24轮），所有12例原分母保留；模型digest、CSV/知识资料、采样及非意图参数必须相同。每次新结果目录，不拼接最好单题，运行后按计划封存。保存完整工具轨迹、实际入模资料与经过校验的程序引用，逐轮评分绑定result_sha256。Runtime追踪与操作日志不含用户原文；受控评测原始题/输出与作者审核文件是评测资料，不冒充生产日志。

报告两种模式各自全轮通过数、逐轮内容与忠实度、工具选择、同题进步/退步/共同通过/共同失败/未知及每轮延迟、额外意图调用和预算跳过。样本12例只看方向；不做统计显著性、跨域或生产可靠性承诺。辅助标签由助手团队编制，项目作者审核尚未完成，非独立外部专家盲评。
