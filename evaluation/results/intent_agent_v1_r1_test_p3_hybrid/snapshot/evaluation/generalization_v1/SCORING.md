# 新题泛化测试固定评分规则

本规则、案例与金标准在本集首次项目模型推理前冻结。本轮只测当前版本，不根据本集答案修改检索参数、提示、业务实现或金标准，不挑选重跑的最佳结果。旧集已用于修复，不能再当未见测试；两套不同题的分数差不能解释成版本提升。

## 内容与依据

- 内容分 2：回答题目明确请求的全部关键事实、步骤和必要条件，数值、方向、单位、对象正确；接受同义表达。不强制复述题目未请求的参考扩展。
- 内容分 1：主体正确，但遗漏所求关键点、条件、步骤或范围。
- 内容分 0：错误、答非所问或未回答有据可答的问题。
- 忠实度单独判断：核心与新增具体事实均须受本轮真实模型输入、有效工具结果、明确用户历史或经生产校验的程序引用资料支持。知识库另处存在某事实不代表本次有依据；不能把程序直接引用资料计算成模型输入资料覆盖。
- 知识严格通过：执行完成、内容 2、忠实度真。检索命中与工具执行成功不能代替答案判分。
- 资料不足严格通过：明确现有资料不能确认请求的具体事实，不编造数值、因果、型号适用性或数据来源，内容 2 且忠实度真。允许有依据的通用说明、索取资料建议；无关建议不是必答。

## Agent 全轮任务

案例通过要求所有真实轮次内容 2、忠实度真且交付完成。分别保存逐轮判分理由、工具选择和最终任务结果；工具名称正确不代表参数、月份、用户或报告正确。

报告对照受信会话用户与冻结的演示 CSV，只输出用户明确选择的字段。无记录时不能改查相邻月份冒充该月；未提供的字段不得由别的指标反推。跨月差值保留指标与单位，百分率相减使用百分点，缺失值不能当零。资料回答保留机型支持条件，不将通用说明当作具体设备保证。

长历史用 64 对合成已完成消息制造输入长度，不把它们计为真实用户交互、模型成功轮次或真实对话准确率。之后的真实回忆与实际工具任务各自判分；摘要生成成功不等于目标、对象、否定限制都保留。

## 计划分母、覆盖与方法边界

40 案例分别报告知识 28、资料不足 6、Agent 6，以及真实提问轮数。超时、异常、截断、未执行和未复核全部保留原计划分母，缺评分不得默认通过。28 知识题的 `evidence_policy=all` 要求全部标注锚达到来源匹配且字符覆盖至少 60%；这是有限标注证据覆盖，不是穷尽语义召回率或答案准确率。另记实际模型输入覆盖与程序引用路径。

新题依据现有项目演示资料构造，测同一知识域内的新事实与任务组合。标注并非独立真人专家审核，来源本身未验证为真实厂商手册。本次只有当前版的一次串行运行，没有旧版同题对照、生产流量或重复测量，不证明跨领域泛化、统计显著提升或真实设备维修安全。

复核由 Codex 助手团队按冻结题、实际输入和原始输出完成，保存逐题理由及 `result_sha256` 绑定。若发现原标注歧义或错误，保留冻结原版与原分母并注明；另发修订版本，不能按输出回改本轮。完成后保存代码、数据、模型身份、依赖、输出、评分与文件校验清单。
