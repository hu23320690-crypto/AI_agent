# holdout_v2 固定评分说明

评分先于新题推理确定。复核使用题目、冻结金标准、实际给模型的证据或同会话历史、工具轨迹及原始回答；不以受测 Qwen 自评充当独立语义判分。每题应保存理由和可定位的证据。

## 知识回答

内容分为 2（题目所求点完整正确）、1（部分正确或遗漏）、0（错误、答非所问或未回答）。`required_points` 表示题目明确所求的概念与限定，接受同义表达、等价数值书写和合理的单位表示，不要求逐字包含列表字符串。完整步骤问题要覆盖所有请求步骤；只问某项事实时不因为缺少无关扩展步骤而扣分。

数字的方向、范围和对象属于必答：`≤` 不能替换成 `≥`，“2 个百分点”不能混成同比增长 2%，“一般/支持该功能/部分机型”不能扩成全机型保证。V2K02 指定两个部位及资料，必须分别回答；V2K10 按指南第 18 条的卧室建议评分，不以其他静音条目的更低阈值替换所问口径。V2K13 的一般越障值不是每台机器保证；V2K17、V2K18 必须保留机型支持条件。

忠实度单独记录：核心事实和新增具体事实是否得到该次实际送入模型的证据支持。回答碰巧符合金标准，但本次没有资料支持时，不自动记忠实通过。资料被预算裁剪时以裁剪后的实际证据判定，原始检索缓存不足以证明模型见到了证据。内容为 2 且忠实度为真才严格通过；不支持的维修或参数扩展不能因为“看起来合理”忽略。

## 资料不足

6 道题均缺少请求的具体事实；2 分要求明确无法确认且不编造确定数值、参数或设备状态。允许提供有证据的通用说明和获取资料建议。例如 V2N02 可以指向 APP 耗材管理，但不能把常见更换周期当成当前剩余寿命；V2N03 可说明资料中存在一般专用清洁液建议，但不能声称它就是指定第三方产品厂家的准确比例；V2N04 月度 CSV 无法反推单次时间和噪音曲线。

含不确定提示但边界含糊可记 1；编造所求确定事实、错误确认或完全答非所问记 0。单纯“不知道”且确实没有编造可达到正确拒答，不强制建议联系售后才能通过。拒答分母单独报告，不把其并入 28 道知识题准确率。

## Agent 任务

每轮内容和忠实度单独复核；案例任务通过要求所有轮次达到各自要求。工具选择使用每轮 `required_tools` 和 `allowed_tools` 独立计分，不等于语义完成。

- V2A01：只要求 1006、2025-10 的三个指定字段，不能混入其他月份或用户。`1.0 个/月` 与 `1 个/月` 等价。
- V2A02：首轮 11 月为 93%、38㎡；下一月指 2025-12，为 95%、40㎡；变化是 2 个百分点和 2㎡。两轮至少各一次实际查表。允许从先前有效工具结果使用 11 月值，不强制第二轮再次查 11 月。
- V2A03：第一轮需 RAG 获取手机离线条件；第二轮可直接依据同会话证据说明无法保证机器人断网执行，也允许再检索，不能扩大条件。不得因为第二轮未调用 RAG 就扣工具选择分。
- V2A04：不能把扫地滤网当污水仓滤网；后者每周清水冲洗、晾干再用、6 个月更换、破损立即更换。检查第二轮部件指代及新证据。
- V2A05：回忆污水仓滤网目标、晾干提醒和资料不足不猜；此轮无需工具且不允许无关工具。第二轮需检索，并保留维护对象和全部周期/破损要求。上下文摘要即使执行成功，丢失关键限制也须扣语义分。
- V2A06：首轮回忆 2025-09 及两个字段，不需要工具；第二轮查当前受信账号 1004，猫砂泼洒处理 8 次/月、自动回充成功率 88%。记录属于演示数据，不允许写成真实设备遥测。

长历史另记录是否生成摘要、摘要保留/遗漏了哪些目标和限制、每轮 retained message 数量、模型消息与预算估计。注入的 64 对历史与真实后续用户提问分别统计。模板历史未由模型生成，不能作为摘要前真实对话准确率。

## 检索与性能

28 道知识题的 `evidence_policy="all"` 表示全部锚都必须满足冻结覆盖标准；跨段或跨文件题只有部分锚命中，完整证据 Hit@K 为 0，同时可以另报覆盖锚数/总锚数。单锚题与历史覆盖规则一致（标注源、至少 60% 字符覆盖）；这不是穷尽的语义召回率。6 道不足题不计证据命中分母。Agent 在线工具证据另报，不与非 Agent 预检索混为同一分母。

答案层记录预算准入后实际 evidence blocks，区分召回失败、证据被裁掉、模型遗漏/编造和 Agent 条件或指代错误。耗时分开保存检索、RAG 生成、Agent 每轮和案例墙钟；P95 使用 nearest-rank，并写明是否含预先检索、摘要或重试。不得将缓存检索耗时加成未经测量的在线端到端性能。

超时、报错和未知留在原计划分母，未复核不得默认通过。汇总同时列计划数、完成数、已评分数、严格通过数；知识、拒答和 Agent 各自报告。若给出 40 案例整体通过，Agent 每案例按全轮通过算一项，并同时说明各层分数，避免不透明混合指标。40 例属于小样本应用验收，单道题就能改变总体结果 2.5 个百分点，不应据此宣称通用能力提升或统计显著。
