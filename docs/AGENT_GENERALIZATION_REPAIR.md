# 新题暴露问题的修复与同题回归

2026-10-08 完成最终文档与后测整理，依据 [新题首次测试](GENERALIZATION_EVALUATION.md) 暴露的最终交付失败修复实现，再在固定版本上回归 `generalization_v1` 与 `holdout_v2`。保留两套原题、原评分规则、原始首次失败及原计划分母；这两套题已经用于修复，后测不能当作独立未见题泛化成绩。

## 实现变化

- 报告字段接受“剩余寿命”等表达，但按完整指标名称匹配。不会把墙角覆盖率当成覆盖率、污水仓滤网当成通用滤网。报告仍只使用本轮成功、授权的 CSV 结果；基准历史不能代替当前目标的查询。
- 分离目标月与基准月，处理“上个月”、跨年、修正与否定月份。没有可用时间锚时拒绝猜月；跨月差值由程序以 Decimal 计算，百分率使用百分点。
- 报告与知识子问分别交付。记录无法提供原始续航或同名量纲时明确不足，不能将电池衰减率、覆盖率或其他指标冒充续航更换门槛。相对门槛只比较用户请求的同一完整指标。显式要求解释含义时保留本轮成功 RAG 观察，字段列表与否定解释不会误追加说明。
- 当前用户指定的部件优先于历史目标，明确追问继续使用有界原始用户目标。低信任摘要或模型自行改写的问题不能覆盖已经确认的部件；回忆问题不被当作任务换题。
- 在来源、部件和子类型可判定且完整条目能容纳的狭窄场景，从当前批准来源恢复完整条目，保留来源原章节的步骤、条件与频次。最长名称、文件后缀及排除来源参与选择；同名歧义、来源配额或预算不足时不冒充完整引用。引用前后和最终提交均复核当前来源字节、版本与授权。
- 对资料不支持的个体寿命预测保守拒答。最终版本恢复首次测试所用的已测 RAG 提示，保留原有安全与完整性规则；提示不保证步骤完整、部件关联或答案正确。程序引用仅适用于有明确来源与对象的狭窄场景，并非通用答案正确性保证。

对应实现见 [报告解析](../utils/report_intent.py)、[报告渲染](../utils/report_render.py)、[指标与资料判断](../utils/record_evidence.py)、[Agent 出口](../agent/react_agent.py)、[追问目标](../rag/query_context.py)、[RAG 服务](../rag/rag_service.py)及[来源条目选择](../rag/maintenance_answer.py)。新增受控测试使用虚构日期、指标与来源，不在业务代码中匹配评测 ID 或读取金标准。

## 验证约定

本机完整 pytest 为 **669 passed、3 skipped、291 subtests passed，51.03 秒**；3 项跳过均来自 Windows 符号链接权限。离线 doctor 146 项通过，pip check 无冲突。见[检查身份](../artifacts/generalization_repair_v1/checks.json)、[完整日志](../artifacts/generalization_repair_v1/pytest.log)和[离线检查](../artifacts/generalization_repair_v1/doctor_offline.json)。对应提交的 Windows/Linux 和 Docker 验证以 GitHub Actions 为准。

真实评测固定为 Qwen3:4b 与 Qwen3-embedding:4b、原六份知识资料及 120 条演示 CSV，串行运行，每案例外层预算 300 秒，生产整轮预算保持配置。每套 40 案例、45 次真实提问，其中 Agent 11 轮。注入的合成历史单独统计，不能算作真实模型交互。

QA 回放初始检索 Top-5 后调用生产 RAG；新实现可以按明确用户来源恢复批准文件的完整条目。因而分别报告初始检索证据、真实模型输入和程序直接引用。检索命中、工具调用成功、程序引用和最终答案正确四者不能互相替代，也不能把服务侧资料统计成 LLM 实际输入。

完整记录由助手团队依据冻结题目、实际输入与最终输出逐题复核，保存理由和 `result_sha256` 绑定；主助手复核失败与争议项。非盲评、非独立真人专家评测，部分复核助手参与过实现。保留原评分歧义，不因后测答案而改金标准。

此前启动的 `generalization_repair_v1` 诊断在 K06 后因交叉审查发现指标/定义交付缺口中止，原始记录留在本机，不计作完整评测。补充代码和受控测试后，使用新的运行目录固定版本测量，不将不同版本的行拼在一起，不挑选同版本最好一次重跑。

## 适用边界

这是两套已见题的修复回归。只在同一题集内部比较前后，不能由不同题集之间的分差推导提升。多项实现一起变更、小样本、单次测量、助手标注与同域演示资料，不支持单一算法因果、统计显著性、跨域泛化或生产级可靠性的结论。真正的未见题检验需要另冻结新测试集并避免用于调参。
