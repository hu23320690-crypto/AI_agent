## 实施前审查结论（保留作为改进依据）

- agent/react_agent.py：外层 ModelCallLimitMiddleware 限制 8 次；成功后才提交历史，但没有整轮 deadline。
- model/factory.py：Ollama 客户端每次请求 timeout=120，不能限制整个 Agent 多次调用的总耗时。
- rag/rag_service.py：RAG chain 内另有模型调用，当前未计入外层预算；首次请求还可能触发索引。
- agent/tools/middleware.py：广泛捕获工具异常，必须让取消/预算/超时等控制异常穿透。
- 数据源、索引和提示词仍是本地演示范围；尚无生产认证和文档审批体系。

## 第一步：统一执行控制（已完成）

交付 agent/runtime/：RunContext、配置、截止时间、调用预算、同步执行边界、有限并发、结构化轨迹。

1. 整轮使用 monotonic 截止时间，排队和嵌套调用共享剩余预算。
2. 统一统计真实模型尝试次数（外层 Agent + RAG），限制工具次数、输入/输出长度。
3. 同步调用通过受限后台线程隔离等待；等待超时或取消时迅速返回，禁止迟到结果提交会话。
4. 保留正在运行的调用占用的并发名额，直到其实际结束，防止连续超时创建无限线程。嵌套调用避免占用同一线程池导致死锁。
5. 每个 Agent 实例同一时间只运行一轮；清空历史会撤销当前轮，旧轮不能覆盖新历史。
6. 控制异常不作为普通工具失败反馈给模型继续循环。
7. trace 默认只记录 ID、耗时、计数、状态、错误类型，禁止保存完整提示词、工具参数或资料原文。
8. 现有 execute_stream 接口保留；增加明确取消接口与最近执行摘要。前端显示可理解的超时/预算错误。

验收：模拟模型通过真实 LangChain 图测试；覆盖外层与 RAG 共享预算、工具预算、整轮超时、取消、迟到结果、并发容量回收和既有成功流程。所有原有离线测试继续通过。

边界：线程等待超时不等于杀死线程，也不保证停止远端 Ollama 推理；底层仍受客户端 I/O timeout 约束。强制终止阻塞任务需后续进程隔离。当前只读工具可安全丢弃结果，未来外部写操作必须另外设计幂等/补偿。第一阶段不是生产级沙箱，不实现认证，不宣称有重试/熔断/投毒防护。

## 第二步：有限重试与依赖熔断

- ModelGateway 与工具依赖适配器统一维护 retry policy；仅对明确瞬态故障重试，次数、退避等待均计入第一步预算。
- 同一调用链仅一层负责重试；参数错误、权限拒绝、查无记录、主动取消不重试。
- 按依赖维护跨请求 CLOSED/OPEN/HALF_OPEN 状态，使用锁保证只有有限半开探测。正常数据缺失不得计入依赖故障。
- 配置最小样本/失败阈值、观察窗口和恢复等待；阈值先用模拟故障验收，之后用运行数据调整。
- 有副作用工具默认不自动重试，除非实现幂等键与结果核对。
- 熔断时明确告知依赖不可用，不生成伪造的业务结果或知识库依据。

验收：假时钟、脚本化异常测试重试次数、退避上限、并发探测、跨请求恢复；真实模型只做小规模冒烟，不人为关闭用户的 Ollama 服务。

## 第三步：RAG 数据治理与执行权限（已完成）

- 首先定义威胁模型：攻击者可提供待入库文档，不能修改应用配置/审批记录/程序/应用维护的索引；本机管理员不在此防护边界内。
- 文档清单含来源 ID、版本、SHA256、审核状态；新增和变化文档进入隔离区。现有 6 份演示资料只能记录为演示允许源，不能声称已由厂商核验。
- 索引附带来源版本和片段 ID；检索只使用当前允许的来源版本，撤销文件同步使向量/词法缓存失效。
- 检测可疑指令、隐藏字符、重复片段作为风险信号；控制单一来源占比。规则检测不能证明内容真实，也不能消除提示注入。
- 检索内容以明确的低信任资料结构传入模型，保留来源。RAG 生成子链不获得工具执行权限。
- 工具执行器校验工具白名单、schema、参数大小和当前会话范围；工具结果同样按低信任内容处理。
- 演示 ID 仍不是认证。真实多用户 ACL、外部写入和网络出口控制在接入对应能力时另外实现，不添加虚假的权限保证。

验收：未批准/篡改/撤销来源不得参与检索；正常资料仍能使用；错误用户参数在执行前被拒绝；所有拒绝有可追溯原因。记录检索与回答质量变化。

## 第四步：测试 Harness、投毒评测与交付

- 故障集：模型阻塞、工具阻塞、连续失败、恢复、无限工具循环、取消后迟到、并发占满。
- 攻击集：文档伪造系统指令、诱导越权调用、篡改事实、重复资料挤占检索；使用本地合成攻击资料与临时索引，避免污染现有知识库。
- 正常对照：包含安全知识/引用攻击文本的合法文档，检查误拦截；保留原问答对照。优先复核第三步A11断电追问的实际召回不足，并通过消融检查来源配额与排序的质量取舍；K14须统一范围完整性评分口径。
- 规则断言验证越权动作是否真实发生；真实模型评测保存原始结果，事实正确性单独评分，不能将模型完成运行当成防护成功。
- 报告样本数、模型版本、攻击成功率、误拦截率、正常问题表现、失败案例与限制；不宣称消除 RAG 投毒。
- 更新 README、运行文档、打包和评测快照范围；提供可复现命令。
