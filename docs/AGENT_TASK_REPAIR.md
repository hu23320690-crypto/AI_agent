# Agent 任务交付修复（2026-10-07）

本次针对 [上一轮评测](EVALUATION_V2.md) 暴露的指定字段、跨月比较、长历史目标丢失、生成截断和维护条件遗漏进行修复。上一轮原始记录、题面、金标准与分母保留。已经查看并据此修复的 holdout_v2 现在用于回归，不能再当作未见过的独立测试集。

## 实现

- 报告按当前用户要求选择字段，从已授权工具记录发现指标名称。未知字段明确说明未提供；完整报告仍可显式请求。跨月差值由 Decimal 计算，百分比变化使用百分点；缺少基准或单位不同不推算。
- 会话最多保存24份已核验查表结果，以及解析后的月份、字段、比较基准。仅成功提交才更新，失败和取消不提交；清空和历史来源失效同时清除。不从模型文字或摘要恢复数值。
- 当前目标月份必须来自本轮查询结果；此前缓存只支持比较基准。模型查错月份时明确本轮未查到指定月份，不能把旧值伪装成本轮查询。
- 已完成报告的绝对选择条件作为低信任 Human 引用提供给模型，避免压缩后重复推进“下一月”。引用自身有1024字节限制，预算不足可移除；原始问题仍受正常准入检查。
- 旧轮次从最早开始按完整轮次分块，合并前一块摘要，最多3次摘要调用，预留至少2次主模型调用。摘要总等待最多20秒且不超过剩余时间的三分之一。另保留有界任务原文，重复准备进度不替代初始目标；摘要失败不提交失败的模型内容。
- RAG保留用于检索的指代补全问题，同时接收用户原始请求，避免工具改写淡化问题要求。维护回答保留动作后条件和提前更换例外；前提改变但没有对应依据时明确无法确认。
- 检索补充引用只来自用户原文，JSON最多1024字节。进度过滤允许数字两侧空白；使用完整64对合成历史验证检索入口，避免只在摘要层保留目标、在检索层丢掉。明确的新对象优先，可选补充过大时移除，当前问题完整保留且在生成请求中只出现一次。
- 对象明确、动作匹配的维护周期查询完整引用单行条目；比较多个对象、询问操作步骤或未提供的晾干时长时回退生成。单个判断问题与资料问答有足够词重叠且无歧义时引用原答案。两条路径都不改写数值或补充结论；歧义、冲突、弱匹配和多问回退受约束生成。生产路径从当前ledger加载同版本原文，核实chunk offset与完整物理行边界，不只信任句点或末块metadata。加载前后及最终提交仍核查授权。
- 对明确要求在否定或改变前提后保证执行结果的问题，知识服务保守拒绝保证并说明无法确认。该路径仍检索并校验资料、保留提交前检查，不让生成模型扩大条件。这是应用应答策略，不是证明模型理解了逻辑，也不是完整的语义蕴含检测；可能拒绝资料本来可以充分回答的保证类问法。
- 上述保证边界也应用于Agent最后出口，避免模型不再调用检索工具时绕过。当前追问与已有条件资料片段分别引用；只能使用捕获并复核的EvidenceCheck，模型历史和摘要不能充当来源权威。来源已失效时清除引用，不恢复旧事实。
- 对明确引用产品名称并要求厂家参数的问题，当前资料未出现该名称时，程序明确无法确认，不把通用比例等参数移植成该产品的厂家标准。该规则只覆盖显式带引号的名称；名称出现也不证明参数适用或真实。
- RAG使用独立推理开关和只有 answer 字段的受约束 JSON，严格解析后返回普通文本。实际本机 Qwen 模板即使收到 reasoning=false 仍会思考，不能只以开关值宣称修复；格式约束用于绕开此兼容问题。截断、重复键、额外字段和错误类型仍拒绝。

pytest **505项通过、3项Windows符号链接权限跳过、290个子断言通过**，耗时48.26秒。离线doctor146项通过，pip check无依赖冲突；依赖锁未更改。测试验证程序控制；真实答案按冻结题面与实际输入另外复核。Windows/Linux和容器结果需看本次提交的CI，不能沿用旧提交的通过结果。

已见题回归由主助手逐项审核，非盲评，尚无独立真人或领域专家审核。上述对照同时改变记忆、范围解析、生成格式和应答策略，不能归因于单项算法。保留所有未通过案例；不宣称40题全对或未见题泛化已提升。

## 验证方法与证据

定向测试覆盖字段范围、未知字段、跨年比较、百分点、失败轮次回滚、会话隔离、压缩后相对月份、引用预算、最早目标保留、分块覆盖、摘要失败、取消与撤销、RAG格式和原始请求传递。全量 pytest 同时检查 API、Runtime、来源治理、故障与安全 Harness；脚本模型用于验证程序控制，不代表真实答案正确。

真实复测使用同一冻结40题、资料、模型 digest 与生产入口，记录实际模型输入、格式、工具结果、摘要、预算和最终答案。Agent为6案11次真实提问；两个长历史各注入64对合成已完成消息，不计作128轮真实模型交互。知识与资料不足按原评分规则分别复核，不以成功退出充当正确答案。

证据入口：[本机检查](../artifacts/agent_task_repair_v1/checks.json)、[pytest](../artifacts/agent_task_repair_v1/pytest_complete.log)、[运行目录](../evaluation/results/agent_task_repair_delivery_v4/)、[本轮复核](../evaluation/results/agent_task_repair_delivery_v4/reviews.jsonl)。

程序直出路径的实际资料输入另存为`rag_answers`；它不计作资料已进入LLM。`actual_input_evidence`仍只统计真实生成请求中的资料，不把程序引用路径虚计为模型证据覆盖。

本轮沿用冻结题面的内容完整性规则。程序引用路径的忠实度对照该次服务实际接收并通过来源校验的资料；模型生成路径对照实际送入模型的资料。复核由主助手完成，非盲评，尚无独立真人或领域专家审核。

复现需准备README要求的模型、tokenizer和获准索引，使用不存在的新目录：

```powershell
.\.venv\Scripts\python.exe -B -m evaluation.run --dataset evaluation/holdout_v2/cases.jsonl --run evaluation/results/my_agent_repair --stage all --timeout 300
.\.venv\Scripts\python.exe -B -m evaluation.report --run evaluation/results/my_agent_repair
```

第二个命令只汇总已另行完成的语义复核，不自动评分。

## 限制

关键原文引用不是无损记忆：首目标最多512个UTF-8字节，最近两项各256字节。单个完整工具轮超大，或摘要调用/时间预算不足时，仍会有明确记录的遗漏。规则式字段与月份解析不能覆盖任意自然语言表达。资料问答匹配使用词重叠，不是完整语义蕴含判断；维护抽取只支持完整单行条目，不拼接被截断的条件。来源批准不保证事实真实，生成回退仍可能遗漏或添写。受约束格式不证明答案事实正确，也不消除资料投毒。上线前仍需独立新样本、多次重复测试和实际用户验证。
