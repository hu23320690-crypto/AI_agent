# 已知限制

| 范围 | 当前边界 |
| --- | --- |
| 数据 | 6份内部知识资料、120条CSV演示记录，未接入真实设备/生产业务；知识存在重复和不同维护周期说法，未核实厂商适用性。 |
| 身份 | API 使用共享 Bearer 密钥控制服务访问，不是多租户登录或用户权限体系；拥有相同密钥的调用者不具备独立的数据隔离。CSV ID是演示数据选择，Agent 工具拒绝跨当前会话ID，但模型仍可能尝试错误参数。 |
| 天气 | 实时接口未接入。 |
| 回答 | 原40题仍有7题部分正确，包括操作步骤遗漏和相近部件混淆；知识直出仅避免外层添写，不能消除RAG内部错误。Runtime第三步A11失败保留；第四步已修复来源配额下的证据选择及通用规则适用范围，实际追问正确回答。原40题回答未整体重测，旧指标只代表历史版本。 |
| 评测 | 60例开发集与12例保留题，助手评分，单次串行；缺少独立专家、真实用户和稳定性验证。K01“启动前”题意有歧义，旧记录保留，后续应版本化澄清。 |
| 索引 | TXT、文本PDF，无OCR；新增/变化需重新审核。修改/删除/撤销在检索时校验，sync物理清理。每次核对当前文件和索引，尚未验证大型语料性能。 |
| 规模 | 进程内BM25缓存全部分块，仅验证326块，未测大规模与高并发。 |
| 会话 | 仅当前进程内成功历史，无持久化。已有请求预算、完整轮次裁剪、结构化低信任摘要与失败降级；摘要有损且可能失败，较早信息可能丢失。已验证本地模型可用离线tokenizer计数，其他情况保守字节回退；均含封装估计，不是精确总token硬界。历史资料失效时整体清空原文和摘要；不能收回已展示答案，也不保证即时停止远端推理。 |
| 上下文预算 | 输入预算默认3840估计单位，Ollama生成上限4096 tokens，推理也占生成空间；提供方标记截断的输出不提交。RAG超预算时按排名移除末尾完整证据块，实际送入模型的Top-K可少于检索Top5；旧38/40检索证据指标不能代替当前预算后的上下文/回答评分。当前轮完整工具链超限时直接失败，不截断参数或操作条件。固定tokenizer缓存需在模型/模板变更后重新导出、检查并重启。 |
| 交互 | 当前输出完整答案，不是token级流式生成。 |
| HTTP / asyncio | FastAPI 提供会话、提问、取消、删除和健康接口；asyncio 管理等待，同步 Agent 在有上限的线程执行，并非所有检索/模型调用都已原生异步。超时或断连只触发取消，不能强制终止线程或 Ollama；任务实际退出前保留运行额度。共享密钥、输入限额与错误码不能替代正式认证、速率限制或 HTTPS 网关。 |
| 部署与扩展 | 提供非 root Docker 镜像、Compose 初始化/持久卷和 Linux 运维说明，但本机 Docker 尚未安装，本轮 Linux 镜像构建与容器运行待验证；CI 绿色结果才证明对应提交的烟测通过。只支持一个 API 实例、一个 Uvicorn worker；进程内会话/并发/熔断不支持多副本，重启丢失对话。没有云平台部署、共享会话数据库或自动故障切换。 |
| 执行控制 | 已有整轮 deadline、共享预算、有限并发和取消，以及模型/embedding 请求的有限重试和进程内熔断。同步任务等待超时不自动重试，任务可能继续占用名额；不保证远端停止，未做强制进程隔离或分布式熔断。重启会清空熔断状态。 |
| RAG安全 | 已实现来源清单/版本摘要、隔离和撤销、保守风险信号、资料消息隔离及工具执行前校验。现有源仅演示允许，审批不保证事实正确；假设程序/配置/清单/索引受保护。规则可能误拦截合法引用，不能消除复杂注入或事实投毒。第四步历史23例均完成；上下文最终配置复验23条均记录、22条完成，C01生成截断被拒绝提交，保留为未知。最新获准错误事实2/2被采纳，恶意工具结果直出污染2/2，合法引用初审误拦2/6；有限合成集不能证明全面防护。PDF解析暂无独立进程/硬内存沙箱。 |
| 环境与测试 | 历史固定环境已验证Windows/Python3.12；新增依赖锁共125项，含开发pytest，运行时直接依赖17项。旧259项回归、258通过/1跳过和142项离线doctor是API接入前的历史发布验收；新增API与跨平台结果以本轮记录和对应CI为准，配置CI不等于已运行。模型标签可能更新，应记录digest；硬件不同耗时不可直接比较。tokenizer 默认仅允许loopback，Docker需管理员显式允许精确origin，不接受任意客户端远程地址。 |
